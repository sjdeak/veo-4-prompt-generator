## 🎓 Prompting Tips

### 1. Start from an Example
Starting with a strong example is usually faster than writing from scratch.

### 2. Be Concrete
Clear subjects, actions, setting, mood, and camera language usually work better than vague one-liners.

### 3. Write Like a Director
Think in shots, motion, atmosphere, and intent — not just keywords.

### 4. Iterate in Small Steps
Change one variable at a time so you can learn what actually improves the output.

### 5. Build Your Own Pattern Library
Once you find prompts that work, save and reuse the structure.
