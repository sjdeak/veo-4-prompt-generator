## 🎓 提示词小建议

### 1. 先从示例开始
多数时候，从一个好示例出发，比完全从零写更快。

### 2. 尽量具体
主体、动作、场景、情绪、镜头语言越具体，通常越容易得到更好的结果。

### 3. 像导演一样去描述
多想镜头、运动、氛围和意图，而不是只堆关键词。

### 4. 小步迭代
每次只改一个核心变量，更容易知道什么改动真的有效。

### 5. 建立自己的模式库
一旦你发现某类 prompt 有效，就把结构保存下来反复复用。
